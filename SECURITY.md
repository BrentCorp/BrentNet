# BrentNET security policy

BrentNET is experimental networking software. No formal security audit or complete threat model is claimed.

To report a sensitive vulnerability privately, email **brent@brentnet.net**, the bug-report contact embedded in the current Windows client. Do not include other users' credentials or personal data unless expressly authorized to disclose them. For high-impact issues, avoid public exploit details until coordination and mitigation are possible.

We will document affected versions, verified mitigations, and advisories as fixes become available. The goal is to provide source, release hashes, and transparent security policies for independently verifiable deployment. No guaranteed response-time SLA or bug bounty is currently offered.
