# Source provenance and limitations

Windows v0.2.11 client C# source recovered from BrentNET project attachments: `Program(2).cs` (here `helper/Program.cs`), `HostsManager.cs`, project file, app manifest and routes. Windows installer source (`BNH.iss`) had three absolute build paths replaced with relative ones. Chromium extension v0.1.1 recovered from `background.js` and `manifest.json`. Linux preview source and tests copied from the working Ari-Core prototype as of 2026-11-21. Text line endings may be normalized.

Historical Git tags v0.2.2 through v0.2.11 point to a placeholder snapshot. The source here is the recovered current state, and does not reconstruct earlier version history or prove distributed Windows executable equivalence. Existing historical tags are preserved.
